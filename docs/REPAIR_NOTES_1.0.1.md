# 1.0.1 修正紀錄（歷史版本）

本文件只記錄 1.0.1 當時的修正與未完成事項。SRP／VAR 的文字解碼規則、Type 分類、PUA 表示方式、批次提交及自動測試已在 1.0.2 更新；請以以下文件為準：

- `README.md`
- `docs/FIXES_1.0.2.md`
- `docs/FORMAT_NOTES.md`
- `docs/TEST_PLAN.md`

1.0.1 時曾採用固定 CP932 嘗試、Type 0–3 文字候選與單向顯示替代字元等策略。這些策略不足以處理不同 SRP 來源的 nibble 狀態，也可能讓 Type 2／3 二進位資料被錯誤顯示成文字，或讓一般漢字誤映射成 EUDC。1.0.2 已改用候選判斷、明確格式標頭、Type 0／1 文字限制及 `\g{}` 明確 token。
